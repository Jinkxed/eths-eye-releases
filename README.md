# Eth's Eye releases

Installers for **Eth's Eye**, a buff/debuff timer, spell message and auction price companion for
the MMO *Monsters & Memories*.

Download the latest `eths-eye-setup-*.exe` from [Releases](../../releases). Once installed, the
app updates itself from this page: new versions download in the background and install when you
quit the app (or right away with **Restart to update**). Your settings, triggers, learned spell
messages and trading history are kept.

This repository only holds releases; they're published automatically.
